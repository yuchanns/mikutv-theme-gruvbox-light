# Gruvbox Light for MikuTV

Warm retro parchment and golden ochre daytime palette inspired by Gruvbox Light for MikuTV.

- **Plugin ID**: `gruvbox-light`
- **Kind**: `theme` (`light` appearance, daytime pair for **Gruvbox Dark**)
- **Version**: `1.0.0`
- **License**: Apache-2.0

## Installation

1. Open **MikuTV** on Apple TV.
2. Go to **设置 → 外观与动态 → 白天主题 → 发现更多主题** (or **设置 → 插件管理 → 发现插件**).
3. Select **Gruvbox Light** (`yuchanns/mikutv-theme-gruvbox-light`) and install.
